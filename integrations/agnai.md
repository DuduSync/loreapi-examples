# Agnai

1. Log in to your Agnai instance and open **Settings** > **AI Providers** (or **Services**).
2. Add a new **OpenAI-compatible** provider.
3. Fill in:
   - **Endpoint / Base URL**: `https://loreapi.online/v1`
   - **API Key**: your `sk-lore-...` key
   - **Model**: `loreapi-rp`
4. Select the provider in your chat settings and start a chat.

Notes:

- If your Agnai version asks for the full completions path, use `https://loreapi.online/v1/chat/completions`.
- Streaming works out of the box.
